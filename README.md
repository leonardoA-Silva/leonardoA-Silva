## Sobre mim

Sou desenvolvedor full stack com foco em **aplicações web e mobile**, trabalhando com React, Node.js, TypeScript e React Native. Gosto de transformar ideias em soluções funcionais, com atenção à experiência de uso, à performance e à organização do código.
